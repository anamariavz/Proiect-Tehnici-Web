# Clinica Stomatologică HappyDent — Proiect Tehnici Web

> Unul dintre primele mele proiecte pe GitHub (anul II, semestrul II, disciplina Tehnici Web).

## Descriere

Aplicație web pentru o clinică stomatologică, cu backend Node.js și pagini randate din server (`views`).

## Conținut

- `index.js` — serverul aplicației
- `views/` — paginile aplicației
- `resurse/` — resurse statice (CSS, imagini)
- `servicii.sql` — scriptul bazei de date

## Tehnologii

Node.js · HTML/CSS · SQL
